📊 HR Analytics Dashboard
An interactive HR Analytics Dashboard built in Microsoft Excel to analyze employee data, attrition patterns, and workforce demographics.

📌 Project Overview
This dashboard summarizes key HR metrics and visualizes employee attrition across education, job roles, departments, age groups, and marital status. It is designed to help users explore workforce trends at a glance.
📈 Key Performance Indicators (KPIs)
KPI	Value shown in dashboard
Total Employees	1,470
Attrition	237
Active Employees	1,233
Attrition Rate	16.12%
Average Age	37


📊 Dashboard Visualizations
- Gender by Employees — employee distribution by gender.
- Education-wise Attrition — attrition counts across education levels.
- Attrition by Job Role — treemap view of attrition by job role.
- Department-wise Attrition — comparison across HR, R&D, and Sales.
- Attrition by Age Group — attrition across age bands.
- Attrition by Marital Status — comparison across marital-status groups.
- Interactive Filters — filter the dashboard by education field and department.
🧰 Tools Used
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Slicers / interactive filters
- Data visualization and dashboard design
🎯 Project Objectives
1. Summarize important workforce KPIs.
2. Identify employee attrition patterns across demographic and job-related categories.
3. Present HR data in a clear, visual format.
4. Practice Excel reporting, analysis, and dashboard-building skills.
🚀 How to Use
1. Download or open the Excel workbook associated with this project.
2. Use the education-field and department filters to explore the dashboard.
3. Review the KPI cards and charts to compare attrition patterns.
